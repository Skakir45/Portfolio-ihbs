## 3. Character design specifications

### Sheru Bhai (`src/ad50/characters/SheruBhai.tsx`)
- **Build:** stocky, confident; head about 45% of body height (cartoon proportion). ViewBox 400×820.
- **Head:** two-layer star-shaped golden mane that wobbles slightly each frame (`#9C4A12` → `#E08A22` → `#E8962A`), radial-gradient face `#FFD27A → #E9A23B`, cream muzzle, dark brown nose, whisker dots.
- **Signature:** black wraparound sunglasses with a white glint and gold temples. They're removable (Scene 3 drop, Scene 4 eyes visible, Scene 5 back on).
- **Outfit:** black suit with darker lapels, white shirt, gold tie, thick gold chain with an "S" medallion, gold pocket square, gold cufflinks/watch band, gold shoe buckles.
- **Expressions:** `boss` (smirk), `grin` (teeth), `confused` (uneven brows, wavy mouth), `shock` (huge eyes, O-mouth), `relieved`.
- **Rig:** two-segment arms (shoulder + elbow), hip-pivot legs for walking, head tilt, breathing, dance bounce, procedural lip-sync, auto-blink (when the glasses are off).
- **Pose library:** idle, hipsBoss, raiseRight, count, shrug, hug, bothUp, thumbsUp, shock.

### IHBS Consultant (`src/ad50/characters/Consultant.tsx`)
- **Look:** friendly Malayali professional: warm brown skin `#B97A4C`, neat side-parted black hair, classic Kerala moustache.
- **Outfit:** navy blazer (`#081B33`), white shirt, gold tie, gold lanyard with an **IHBS** ID card, navy trousers, brown shoes.
- **Expressions:** `smile`, `laugh` (closed happy eyes), `proud`, `shock` (raised brows, wide eyes, animated sweat drop).
- **Rig:** same two-segment arms with open-palm and thumbs-up hands, walk cycle, blinking about every 3 s, procedural lip-sync.
- **Pose library:** idle, wave, stop, pointUp, present, handsUp, thumbsUp, shock.

Both characters are drawn only once, as components. Every scene reuses them with props, so the design is guaranteed to stay consistent.

## 6. Preview and MP4 export

Requirements: Node 18+, Python 3 + numpy (only needed to regenerate audio), ffmpeg.

```bash
cd video
npm install
```
Preview in the browser (scrub the timeline, toggle props; the player scales to any window):
```bash
npm run studio
```
Export the MP4:
```bash
npm run render:ad50
```
Export with the recorded voiceover (after adding `public/ad50/voiceover.mp3`):
```bash
npx remotion render SheruIHBSAd50 out/ihbs-sheru-bhai-ad-50s-vo.mp4 --props='{"hasVoiceover":true}'
```
Clean version without burned-in subtitles (for platforms that add captions):
```bash
npx remotion render SheruIHBSAd50 out/ihbs-ad-nosubs.mp4 --props='{"showSubtitles":false}'
```
Regenerate the music and SFX:
```bash
npm run audio:ad50
```

**Safe zones:** subtitles sit at y ≤ 1640 px (the bottom 280 px is kept clear of the Instagram/TikTok UI), and top titles start at y ≥ 190 px.
